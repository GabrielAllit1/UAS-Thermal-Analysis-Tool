Thermal Analysis Application - User Guide

1. Launch the Application:
   Double-click ThermalAnalysis.exe to start the app.

2. License Activation:
   On first run, the app will prompt for a license key.
   Contact support at salt19.llc@gmail.com to obtain a license key.
   Enter the key in the dialog and click "Submit". The app will restart.

3. Using the App:
   - Load a single R-JPEG, a folder of R-JPEGs, or a GeoTIFF file using the respective buttons.
   - Optionally load KML or TFW files for GeoTIFFs.
   - Adjust parameters (emissivity, distance, etc.) as needed.
   - Click "Analyze" to process the images.
   - Click "Generate Report" to create PDF and CSV reports, selecting an output directory when prompted.

4. License Renewal:
   If your license expires, the app will prompt for a new key.
   Contact support at salt19.llc@gmail.com to obtain a renewed license key.
