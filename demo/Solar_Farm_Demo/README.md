# Solar Farm Demo — One-Click Autopilot Learning Mission

This is the public, fully synthetic learning and functional-acceptance mission for UAS Thermal Analysis.

The repository stores the demo blueprint and generator rather than large third-party/customer imagery. The desktop **RUN BUNDLED DEMO** action materializes the small calibrated GeoTIFF mission into the application's local data directory and immediately sends it through the same Autopilot pipeline used for normal work.

## What the demo contains

When materialized, the mission contains four contiguous single-band float32 radiometric GeoTIFF tiles in **EPSG:32617**, synthetic visual context, a site boundary, a synthetic flight path, mission metadata, and machine-readable ground truth.

The synthetic thermal scene contains three intended spatially coherent anomalies:

| ID | Seeded local ΔT | Expected severity |
| --- | ---: | --- |
| DEMO-A001 | +8 °C | Minor |
| DEMO-A002 | +14 °C | Moderate |
| DEMO-A003 | +26 °C | Critical |

It also includes three deliberate robustness challenges: a +3.5 °C warm region below the photovoltaic finding threshold, a +30 °C single-pixel spike that should be suppressed for insufficient spatial support, and a small nodata patch.

## How to use it

1. Install the normal desktop/geospatial/reporting extras.
2. Launch `python -m uas_thermal desktop`.
3. On the first Autopilot screen, click **RUN BUNDLED DEMO**.
4. Do not configure anything else. Watch Autopilot discover, classify, stitch, analyze, annotate, and package the mission.
5. Open the completed deliverable and inspect the PDF, annotated evidence, GeoTIFF, CSV/JSON, GIS outputs, portable viewer, processing provenance, and manifest.

Developers can also materialize the same mission programmatically with:

```python
from uas_thermal.validation.demo_mission import materialize_demo_mission

print(materialize_demo_mission())
```

## Claim boundary

This mission is deterministic **synthetic functional acceptance data**. It is designed to prove installation, mission intake, radiometric GeoTIFF handling, quantitative stitching, anomaly detection/suppression behavior, annotation, reporting, packaging, and optional local-AI integration. It is **not** field-validation evidence, thermographer certification, or proof of universal detection accuracy.

All demo imagery and metadata are generated by this repository and may be redistributed with it.
